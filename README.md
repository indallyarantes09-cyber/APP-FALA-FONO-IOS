# Fala Fono iOS

Projeto iOS baseado no Fala Fono PC 0.2.0. O arquivo FalaFono-iOS.zip contém o projeto Xcode compatível com iOS 18 ou posterior.

O workflow do GitHub Actions compila o projeto em um runner macOS hospedado e disponibiliza o artefato FalaFono-IPA-sem-assinatura.

O IPA não contém assinatura nem perfil de provisionamento; portanto, serve para arquivamento e inspeção, mas não para instalação no iPhone ou envio à App Store.
